02_React Native TS

створити React-Native TS пишемо 	--	JS-частина (JavaScript Side)
	npx create-expo-app@latest


https://reactnative.dev/docs/set-up-your-environment

Requirements:
	node --version
	java --version

	
	1. додаємо змінну середовища ANDROID_HOME
		та пропис шлях із AndroidStudio -> tools -> SDK Manager
	
	зазвичай 
		....\AppData\Local\Android\Sdk
	
	2. Додаємо до PATH
			....\AppData\Local\Android\Sdk\platform-tools
	
	3. додаємо змінну JAVA_HOME
		...ProgramFiles\Microsoft\jdk-17.0.19.10-hotspot\
	

Створення
	npx create-expo-app@latest
	
		Expo go SDK 54	

Запуск
	npx expo start

Щоб запустити проект власний проект на телефоні треба підлкючити комп і телефон до 1 мережі 

	VYSOR для підлкючення екрану телефону 	(через провід)
	npm expo start --tunnel  					(через QR)


npm install --global @expo/ngrok@^4.1.0		--встановити ngrok для підключення з телефону

для підключення з tunnel ще можна
	скачати додаток expoGo


Пофіксити помилки при запуску:
	npm uninstall -g @expo/ngrok
	npm install -g @expo/ngrok@^4.1.0
	npx expo install @expo/ngrok@^4.1.0
